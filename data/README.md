# 数据说明

## 文件列表

| 文件 | 记录数 | 说明 |
|------|--------|------|
| db_dipeptides.csv | 389 | 二肽稳定性参考数据库 |
| db_pentapeptides.csv | 40656 | 五肽稳定性参考数据库 |

## 数据格式

两个 CSV 文件格式相同，包含以下列：

| 列名 | 说明 |
|------|------|
| peptide | 肽段序列（单字母氨基酸代码，长度=2 或 5） |
| ss | 二级结构类型：H = 螺旋（helix），E = 折叠（sheet） |
| db_value | 稳定性评分（正值=稳定，负值=不稳定） |
| rule | 规则标签（over / under） |
| thermo_mean | 热力学均值 |

## 数据来源

数据库基于蛋白质热稳定性实验数据构建，通过统计不同二肽/五肽序列在不同二级结构中的出现频率和热力学贡献生成。数据用于本项目的残基级稳定性打分，不涉及受控或受限数据集。

## 使用许可

数据随项目一起发布，仅供本比赛评测使用。
