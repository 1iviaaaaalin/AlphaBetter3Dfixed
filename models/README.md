# 模型说明

本项目**不使用训练的深度学习模型**，采用传统计算方法。

## 技术路线

1. **二级结构识别**：基于 PDB 注释 + 几何/氢键规则（USSA 风格），无需训练。
2. **稳定性打分**：基于二肽/五肽参考数据库的查表匹配，无需训练。

## 第三方组件

| 组件 | 版本 | 用途 | 调用方式 |
|------|------|------|---------|
| NGL.js | 2.0.0-dev.37 | 前端 3D 分子渲染 | `<script>` 标签加载，MIT 许可 |
| numpy | 2.4.6 | 坐标计算 | Python import，BSD-3 许可 |

## 本项目创新贡献

- 双保险二级结构识别（PDB 注释优先，几何推断兜底）
- 二肽+五肽组合打分策略
- B-factor 着色 PDB 输出，兼容主流可视化工具
